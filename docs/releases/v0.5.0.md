# v0.5.0

## 概要

`dsh-sdd-kit` v0.5.0 是宏观架构评审（Linus 判据）落地后的第一个发布：**删掉第二套机制，让每个事实只有一处可编辑**。插件不再自研安装器、不再平行勾选任务、不再把安装产物入库；`/sdd-setup` 的状态机从 markdown 搬进可测试的代码。对外表面仍是 **2 个技能 + 2 个 Host 工具 + 1 个 Spec Kit 扩展**，章程升至 **v4.0.0**。

这是一次**破坏性变更**：多个工具动作与参数被删除，`update_all` 语义收缩。迁移只需升级插件、重启 DSH、重跑一次 `/sdd-setup`。

## 破坏性变更

- **`update_all` 从三层降为两层**：只刷新 `specify-cli` 与 `~/.dsh/upstream/superpowers` 镜像。`dsh-sdd-kit` 自身的安装与升级归 DSH 包管理器（`dsh plugin --profile <profile> update dsh-sdd-kit --latest` + 重启）。`src/core/kit-copy.mjs`（245 行自研安装器）整体删除。
- **删除参数**：`dshKitSourceDir`、`dshProfileDir`、`force`（自认 no-op 的死接口）、`taskMatch`。
- **删除 `sdd_bridge(check_task)`**：`tasks.md` 勾选的唯一写者交还上游 `/speckit.implement`；bridge 只保留 `inspect` / `install_overrides` / `sync_index`。
- **安装产物退出 git 跟踪**：`.dsh/`、`.specify/extensions/`、`.specify/extensions.yml`、`.specify/integrations/*.manifest.json`、`.specify/templates/overrides/`。新克隆的仓库运行一次 `/sdd-setup` 幂等重建。治理文档 `.specify/memory/constitution.md` 与上游脚本/模板仍在库中。
- **未知动作不再抛异常**：返回 `{ ok: false, error: { code: 'E_ARGS', message, hint } }`。

## 新增

- **`sdd_upstream(action: "setup")`**：`/sdd-setup` 的 7 步状态机进代码，返回可断言的 `steps` 数组（`performed` / `skipped` / `failed`）。技能降为 ~30 行声明式命令。新增可选参数 `switchIntegration`（显式 opt-in 切换 integration）、`upgrade`（强制升级 specify-cli）。
- **bug 扩展幂等确保安装**：`install_bug_ext` 恒传 `--force`，且 setup 每次运行都确保两个扩展在册——修复了既有项目永不补装 bug 扩展的缺口。
- **扩展元数据单一事实源**：`install_hooks_ext` 运行期从 `extension.yml` 定向读取 id/version/事件（零依赖固定键读取器），删除手写常量。
- **平台支持矩阵**：Linux/macOS/WSL 一级支持；Windows 原生已验证（44 测试全绿），CLI 无 symlink 权限时钩子技能回退为内容一致的副本。

## 变更

- **行尾统一 LF**（`.gitattributes`），契约测试不再锚定平台换行；symlink 用例在受限平台显式 skip。
- **章程 v4.0.0**（MAJOR）：原则 I 新增三条硬边界——禁止自替换已安装副本、禁止平行任务勾选写者、同一事实唯一可编辑源；原则 V 改为包管理器升级路径；行尾与平台约束入章。
- `peerDependencies` 保持 `"*"`：宿主包版本下界待在可读取的 DSH profile 上核实后收紧（不臆造版本号）。

## 行为保证

- **幂等**：重复运行 setup，既有 `.specify/` 布局永不被重跑 init（REQ-15）；两个扩展 `--force` 重装无重复条目。
- **只报告不切换**：integration 不一致默认只报告，切换必须显式 `switchIntegration: true`（REQ-16）。
- **失败不阻断**：Superpowers 同步失败不阻断扩展安装（REQ-11），报告中如实标 failed。
- **不碰上游**：插件不解析 `extensions.yml`，不复制上游逻辑，不替换运行中的自己。

## 升级步骤

```bash
# 1. 包管理器重新解析 git 依赖（只重新 add 同一来源会被锁文件跳过）
dsh plugin --profile web update dsh-sdd-kit --latest

# 2. 重启 DSH（工具代码有变更）

# 3. 在项目里重建安装产物与扩展
/sdd-setup
```

升级后确认：`specify extension list` 应显示 `Superpowers Hooks (v0.1.0)`，Commands: 4 | Hooks: 4。

## 安装

```bash
dsh plugin --profile web add https://github.com/bobo522487/dsh-sdd-kit
```

或本地压缩包：

```bash
dsh plugin --profile web add ./dsh-sdd-kit-0.5.0.tgz
```

安装后**重启 DSH**，然后在项目里运行 `/sdd-setup`。
